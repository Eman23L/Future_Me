# FutureMe Codex Safety Rules

- Do not expose private keys.
- Do not commit `.env`.
- Do not break PWA installability.
- Do not break iPhone push notifications.
- Do not remove Supabase/Vercel env variable support.
- Do not make unrelated refactors during focused loops.
- Do not run long hidden dev servers.
- Always run build.
- Keep mobile-first UI.
- Keep soft FutureMe tone.
- Do not treat notifications as the main product.
- Do not make the app dependent on push notifications.
- Do not change approved UI styling without explicit instruction.
- Preserve the soft FutureMe visual identity.
- Build logic behind the existing UI first.
- What’s Next is the product.
- Notifications are nudges.
