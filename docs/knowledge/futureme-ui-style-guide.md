# FutureMe UI Style Guide

## Approved Style

The current FutureMe UI style is approved and must be preserved unless explicitly changed later.

FutureMe should feel like:

- Soft wellness app.
- Warm typography.
- Gentle copy.
- Pink/cream/pastel aesthetic.
- Mobile-first cards.
- Rounded buttons.
- Human tone.
- Calm spacing.
- Supportive companion feeling.

Avoid robotic wording and harsh productivity language.

## Copy Examples

Bad: "Generate Schedule"

Good: "Let’s build your month"

Bad: "Notification Settings"

Good: "How should I talk to you?"

Bad: "Task Queue"

Good: "What’s next"

## Implementation Rule

Do not change the visual style, colours, fonts, spacing, card styling, button styling, soft wellness look, or mobile-first layout without explicit instruction.

Logic improvements should happen behind the existing UI first. The daily dashboard UI should not change unless explicitly requested.
