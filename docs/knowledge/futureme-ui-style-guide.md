# FutureMe UI Style Guide

## Approved Style

The FutureMe UI style is a soft, mobile-first wellness style. As of the July 2026 UI refresh, it may be friendlier and more bubbly while preserving the same product flow and colour palette.

FutureMe should feel like:

- Soft wellness app.
- Warm, friendly typography.
- Gentle copy.
- Pink/cream/pastel aesthetic.
- Mobile-first cards and phone-native spacing.
- Rounded, bubbly buttons and controls.
- Human tone.
- Calm spacing.
- Supportive companion feeling.
- Simple enough to use one-handed on a phone.

Avoid robotic wording and harsh productivity language.

## Copy Examples

Bad: "Generate Schedule"

Good: "Let’s build your month"

Bad: "Notification Settings"

Good: "How should I talk to you?"

Bad: "Task Queue"

Good: "What’s next"

## Implementation Rule

Do not change the colour palette, product flow, or soft wellness identity without explicit instruction.

UI improvements may adjust fonts, border radii, surface softness, and control feel when explicitly requested, but they should not make the app feel like an admin dashboard or productivity tool. The daily dashboard should stay calm and phone-first.

Native browser/iPhone/Android back navigation should behave like the in-app back flow by restoring the previous FutureMe screen or selected date.
