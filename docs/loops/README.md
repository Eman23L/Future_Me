# FutureMe Loop Engineering

Loop engineering means repeated focused improvement cycles.

A loop is:

- One focused improvement cycle.
- One goal.
- One set of files.
- One test/build process.
- One result summary.
- One next action.

Codex should not try to solve everything in one loop. Each loop should start by reading the current project knowledge, make one focused improvement, run tests/build, record what changed, record what still needs doing, and create the next recommended loop.
