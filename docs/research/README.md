# FutureMe Research Notes

Deep research should be saved into Git so Codex can reuse it later instead of starting from scratch.

Use this structure:

- Topic.
- Why it matters.
- Findings.
- Implications for FutureMe.
- Implementation notes.
- Risks.
- Links/sources if available.
- Next questions.

Research should connect back to product logic, scheduling rules, What’s Next, database design, notification nudges, and the approved mobile-first UI.
