# Neurodivergent Planning Patterns

## Topic

Planning support for users with executive-function overload.

## Why It Matters

FutureMe should reduce planning load rather than become another system the user has to manage.

## Findings

- Executive function support should reduce decisions.
- Focusing on today can be calmer than showing the whole month at once.
- Gentle task presentation matters.
- Days should not be overloaded.
- Recovery needs protection.
- Completion persistence helps the user see progress.
- What’s Next can act as a supportive focus tool.

## Implications For FutureMe

The daily dashboard should answer "what now?" quickly. Capacity should soften the plan. Missed tasks should be handled gently.

## Implementation Notes

Prefer clear current/next task logic over dense task queues. Use supportive copy consistent with the approved UI style.

## Risks

- Too many controls can increase planning overhead.
- Overdue lists can feel punishing.
- Notifications can become stressful if overused.
